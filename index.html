BROWSER LIMITS

What the website can read

On Chrome or Edge, the folder picker can read folders that Windows has mounted and that you explicitly select.

  • Browse folders and file names
  • Preview text and images
  • Select an ISO / IMG file for the virtual PC
  • No raw USB sectors or boot-area access
  • No direct boot of a Rufus-flashed physical USB

Important: a bootable USB written by Rufus is not the same as an ISO file. The browser can inspect files on a partition Windows exposes, but it cannot read the complete physical USB image or start the USB as raw hardware. To run an OS in this website, choose the original ISO / IMG file from the USB (if you saved it there) or use the built-in Restore Lab image on the Browser OS page.
