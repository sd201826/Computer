02 / USB PREPARATION

Use a real USB drive

This page can guide you, but it cannot take control of a flash drive like a desktop program can.

▰DEVICE ACCESS

USB detection is handled by Windows and Rufus.

For safety, browsers cannot directly list, format or write raw USB storage devices. Plug in your flash drive and check that it appears in File Explorer or Rufus.

Direct USB access: unavailableThis website has not scanned or changed any drive.

RUFUS WORKFLOW3 STEPS
01
Connect the flash drive

Use a USB drive with enough free capacity. Copy anything important off it first.

02
Select the real ISO in Rufus

Choose the USB device and the genuine Windows ISO you downloaded from Microsoft.

03
Write and boot

Rufus will erase the selected USB. Use your computer's one-time boot menu to start from it.

!

Important: Check the selected drive carefully. Rufus formatting permanently removes the files on that USB drive.

04 / COMPUTER RESTORE

A safer restore checklist

Follow the order. Do not format a drive unless you have a verified backup and know exactly which disk you selected.

01⌁

Back up

Copy documents, photos and important files to a separate safe location.

02⬇

Get real media

Download installation media from Microsoft or use your original licensed media.

03▰

Prepare USB

Use Rufus with the correct ISO. Remember that writing the image erases the USB.

04⌘

Choose repair first

When available, try Windows Recovery or Startup Repair before a clean installation.
