BROWSER LIMITS

What the website can read

On Chrome or Edge, the folder picker can read folders that Windows has mounted and that you explicitly select.

  • Browse folders and file names
  • Preview text and images
  • Select an ISO / IMG file for the virtual PC
  • With the Windows helper, read Rufus USB sectors in read-only mode
  • Optionally save a complete copy in browser storage (OPFS)

Important: a Rufus-written USB can be connected through the optional Windows USB Bridge. The helper is read-only and must remain open while booting directly from the USB. You can also save a full copy in browser private storage (OPFS), if enough space is available. See the Browser OS page for the bridge controls and Windows helper download.
