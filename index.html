03 / USB PREPARATION

Create the installer USB with Rufus

Use Rufus on Windows to write the Restore Lab installer ISO to a flash drive. The website itself cannot write to USB storage.

▰DEVICE ACCESS

Write the installer ISO with Rufus.

Download Restore-Lab-Installer-amd64.iso from the release page. In Rufus, choose your USB device and the ISO file. This creates bootable Restore Lab installation media.

Direct USB access: unavailableThis website has not scanned or changed any drive.
Open official Rufus website ↗
RUFUS WORKFLOW3 STEPS
01
Download the Restore Lab ISO

Get Restore-Lab-Installer-amd64.iso from the GitHub release page. Copy anything important off your USB first.

02
Select the Restore Lab ISO in Rufus

Choose your USB device and the Restore Lab installer ISO. Check the device name and capacity before writing.

03
Boot and run the installer

Restart, choose the USB from the one-time boot menu, then select Install Restore Lab. Use a separate target drive; do not select the USB you booted from.

!

Important: Rufus erases the selected USB. Later, the operating-system installer can also erase the target drive, including Windows and personal files. Back up first and ask for help if you are unsure.

05 / COMPUTER RESTORE

A safer restore checklist

Follow the order. Do not format a drive unless you have a verified backup and know exactly which disk you selected.

01⌁

Back up

Copy documents, photos and important files to a separate safe location.

02⬇

Get real media

Download installation media from Microsoft or use your original licensed media.

03▰

Prepare USB

Use Rufus with the correct ISO. Remember that writing the image erases the USB.

04⌘

Choose repair first

When available, try Windows Recovery or Startup Repair before a clean installation.
